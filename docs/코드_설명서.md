# 영상 타임라인 매니저 – 사용법 및 코드 설명서

## 1. 실행 방법
1. 압축을 풀고 `run.bat`을 더블클릭합니다. (Python 3.8 이상 필요, 추가 설치 없음)
2. 브라우저가 자동으로 열립니다. 주소는 `http://127.0.0.1:8765/` 입니다.
3. 종료는 화면 오른쪽 위 **[종료]** 버튼입니다. 브라우저 창만 닫아도 3분 뒤 서버가 자동 종료됩니다.
4. 처음 실행 시 Windows 방화벽 알림이 뜰 수 있습니다. 내 컴퓨터 안에서만 쓰므로 "취소"해도 정상 동작합니다.

## 2. 엑셀 작성 규칙
프로그램이 시트 양식을 **자동으로 인식**하므로 두 양식 모두 사용할 수 있습니다.

**머리글형 양식 (현재 권장, 필터 사용 가능)**
| 위치 | 내용 |
|---|---|
| B1 / B2 / B3 | 영상 제목 / 영상 주소 / 업로드 일자 (`2026-11-19`, `2026.11.19`, 엑셀 날짜 모두 가능) |
| `재생 시간` 라벨의 오른쪽 칸 (예: C3 라벨, D3 값) | 영상 전체 길이 (`1:17:46` 등). 1~3행 어디든 `재생 시간`(또는 `영상 길이`) 라벨의 **오른쪽 칸**을 읽습니다 |
| 4행 | 머리글: `타임라인` / `내용` / `키워드` (여기에 자동 필터를 거세요) |
| 5행부터 A열 | 시간 (`1:23:45`, `1;23;45`, `12:34`, `1시간 2분 3초` 가능) |
| 5행부터 B열 | 내용(메모). 셀 안 줄바꿈도 표시됩니다. `(여기에 내용을 입력)` 같은 괄호 안내 문구는 빈 내용으로 처리합니다 |
| 5행부터 C열~오른쪽 | **키워드.** 같은 행에서 오른쪽으로 칸을 계속 늘려 가며 한 칸에 하나씩 적습니다 |

**이전 양식:** 시간이 B열, 내용이 C열, 키워드가 D열부터이고 데이터가 4행부터 시작하는 시트도 그대로 읽습니다.
**인식 규칙:** 어느 행(12행 이내)에 `타임라인` 칸이 있고 그 **바로 오른쪽 칸이 `내용`(또는 `메모`)**이면 머리글형으로 보고, 그 행 아래부터 데이터를 읽습니다. 그렇지 않으면 이전 양식으로 봅니다. 따라서 머리글 글자(`타임라인` 바로 옆 `내용`)는 바꾸지 마세요. 열 위치는 옮겨도 됩니다(예: 타임라인이 C열이면 내용은 D열, 키워드는 E열부터).

- **필터·정렬:** 엑셀 필터로 행이 숨겨지거나 정렬 순서가 바뀌어도 프로그램은 모든 행을 읽고 시간순으로 표시합니다. (필터로 숨긴 행도 프로그램에는 나타납니다.)
- **파일 하나 = 폴더, 시트 하나 = 영상 하나**로 인식합니다. 실제 폴더도 그대로 트리로 표시됩니다.
- **템플릿 시트 제외 규칙:** 시트 이름에 `템플릿`(또는 `template`)이 들어 있고 **B1 제목·B2 주소가 아직 안내 문구이거나 비어 있으면** 목록에서 제외합니다. 템플릿을 복사해(`템플릿 (2)` 등) 제목이나 주소를 입력하면 이름이 그대로여도 영상으로 표시됩니다. 제외된 시트가 있으면 빈 화면 안내에 개수가 표시됩니다.
- `(시간)`, `(내용)`처럼 괄호로 감싼 안내 문구와 `내용`만 적힌 빈 양식 행은 무시합니다.
- 시간은 `시:분:초` 입니다. `04:12:11`은 4시간 12분 11초이며, 재생 시간보다 긴 시간이 있으면 재생 시간 칸을 무시하고 화면에 안내합니다.
- 시간을 읽을 수 없는 행은 목록에 경고(⚠)로 표시되고 막대에서는 제외됩니다.
- **중요:** 엑셀은 `12:34`처럼 입력하면 "12시 34분"으로 자동 변환합니다. B열을 **텍스트 서식**으로 지정해 두세요. 샘플 파일은 이미 지정되어 있습니다. (시간 값으로 변환된 셀도 읽을 수는 있으나 의도와 다르게 해석될 수 있습니다.)
- 기본 폴더는 `library/`입니다. 다른 폴더를 쓰려면 화면 위 **[폴더 변경]**을 누르세요.

## 3. 화면 기능
- **왼쪽 목록:** 폴더 → 엑셀 파일 → 영상(업로드일 순). 영상마다 썸네일이 표시됩니다. **[업로드일 ↓/↑]**로 정렬, **[보기]**로 폴더별/날짜순 전체를 전환합니다.
- **전체 검색:** 화면 위 검색창이 **모든 폴더·엑셀·시트**를 대상으로 메모, 키워드, 참고자료 이름을 검색합니다. 띄어쓰기로 여러 단어를 쓰면 모두 포함된 타임스탬프만 찾습니다(AND). 왼쪽 영상 목록 오른쪽의 **보라색 숫자는 그 영상에서 검색어가 나온 타임스탬프 수**입니다(마우스를 올리면 단어 일치 횟수도 표시). "결과 있는 영상만" 체크로 결과가 없는 영상을 숨깁니다. 선택한 영상의 막대에서는 일치한 구간이 주황색이 되고 ▼ 화살표가 생깁니다. Enter / Shift+Enter로 다음/이전 결과로 이동합니다.
- **타임라인 목록(접힘):** 기본은 시간과 **키워드 버튼**만 보이고 내용은 접혀 있습니다. ▸ 를 누르면 펼쳐지고, [모두 펼치기/접기]도 있습니다. 검색어가 내용에 있는 항목은 자동으로 펼쳐집니다.
- **내용 수정:** 펼친 내용이나 아래 상세 영역의 [✎ 내용 수정]을 누르면 편집창이 열리고, [엑셀에 저장](Ctrl+Enter)을 누르면 해당 엑셀 파일의 내용 열(머리글형은 B열, 이전 양식은 C열) 셀 하나만 수정됩니다. 저장 직전에 원본이 `library/.backup/`에 자동 백업됩니다(파일당 최근 10개).
- **키워드 버튼:** 누르면 **같은 키워드가 적힌 다른 타임스탬프**(다른 영상 포함)를 내용 일부와 함께 미리보기 창으로 보여주고, 항목을 누르면 그 영상·위치로 이동합니다. 같은 창에서 **버튼 색**을 고르면(기본 색 8개 또는 직접 선택) 해당 키워드의 모든 버튼에 적용되고 `timeline-refs.json`에 저장됩니다. 키워드는 대소문자·앞뒤 공백을 무시하고 같은 글자일 때만 같은 키워드로 봅니다.
- **막대:** 클릭한 위치에 해당하는 구간의 메모를 아래에 표시합니다. **[바로가기]**는 해당 타임스탬프(`&t=초`)로 영상을 엽니다.
- **참고자료:** 선택한 타임라인 지점에 컴퓨터의 파일(텍스트, 이미지, PDF 등)을 연결합니다. 연결할 때 표시 이름을 정할 수 있고, 이름 변경(✎)과 연결 해제(×)가 가능합니다. 클릭하면 미리보기가 열리며 **[기본 프로그램으로 열기]**, **[폴더에서 보기]**도 지원합니다.
- **재생 시간:** 엑셀의 재생 시간 칸을 막대 전체 길이로 사용합니다. 칸이 비어 있으면 "마지막 타임스탬프 + 여유"로 추정하며, 이때는 화면에서 직접 입력할 수도 있습니다. 엑셀 값이 마지막 타임스탬프보다 짧으면 무시하고 안내합니다.
- **자동 반영:** 엑셀을 저장하면 3초 안에 화면에 반영됩니다.

## 4. 파일 구성
```
영상_타임라인_매니저/
├─ run.bat              실행 파일
├─ app.py               서버 (엑셀 읽기, 참고자료 저장, 파일 열기)
├─ web/index.html       화면 뼈대
├─ web/style.css        화면 디자인
├─ web/app.js           화면 동작 (검색, 막대, 참고자료)
├─ config.json          (처음 폴더를 바꾸면 생성) 라이브러리 폴더 경로
└─ library/             엑셀과 참고자료를 두는 기본 폴더
   └─ timeline-refs.json   참고자료 연결 정보 (엑셀과 별도 저장)
```
**수정·업데이트:** `app.py`, `web/` 안의 파일만 교체하면 됩니다. 내 데이터(`library/`)는 건드리지 않습니다.

## 5. 사용한 코드·방법과 이유
| 항목 | 사용한 방법 | 이유 |
|---|---|---|
| 서버 | Python 표준 `http.server.ThreadingHTTPServer` | 추가 설치가 없고 압축 해제 후 바로 실행됩니다. |
| 엑셀 읽기 | `zipfile` + `xml.etree.ElementTree`로 .xlsx를 직접 해석 | openpyxl 같은 외부 패키지 없이 동작합니다. 읽기 전용이라 원본 엑셀을 손상시킬 위험이 없습니다. |
| 시간 해석 `parse_time` | 정규식으로 `:`/`;`/한글 단위를 통일해 초로 변환, 엑셀 시간값(하루=1인 소수)도 처리 | 입력 방식이 섞여 있어도 읽히도록 하기 위함입니다. |
| 참고자료 저장 | 엑셀이 아닌 `timeline-refs.json`에 별도 저장 | 엑셀을 열어 둔 상태에서도 저장되고, 엑셀 서식이 깨지지 않습니다. 임시 파일에 쓴 뒤 교체(`os.replace`)하고 `.bak` 백업을 남깁니다. |
| 참고자료 경로 | 라이브러리 폴더 안은 상대경로, 밖은 절대경로 | 폴더째 옮겨도 링크가 유지되도록 하기 위함입니다. |
| 파일 선택창 | 별도 프로세스에서 `tkinter.filedialog` 실행 | 브라우저는 파일의 실제 경로를 알 수 없습니다. tkinter는 Windows용 Python에 기본 포함됩니다. 실패하면 경로 직접 입력으로 대체합니다. |
| 파일 열기 | `os.startfile`(Windows), `explorer /select`(폴더에서 보기) | 연결된 파일을 기본 프로그램으로 열기 위함입니다. |
| 변경 감지 | 엑셀 파일의 수정 시각·크기를 3초마다 비교(`/api/stamp`), 변경 없으면 파싱 결과 캐시 사용 | CPU 부담 없이 자동 반영합니다. |
| 막대 | 타임스탬프 사이를 구간(`div`)으로 나눠 `left`/`width`를 %로 배치 | 메모가 "다음 타임스탬프 전까지" 이어진다는 의미를 시각화하고, 클릭 위치를 구간으로 바로 변환할 수 있습니다. |
| 키워드 해석 | D열 이후 셀을 행 단위로 모아 `keywords` 배열로 전달, 서버가 색인 없이 화면에서 `Map`으로 색인 | 키워드를 눌렀을 때 전체 영상에서 같은 키워드를 즉시 찾기 위함입니다. |
| 엑셀 내용 저장 | 시트 XML 문자열에서 **해당 셀 하나만 정규식으로 교체**하고, 나머지 압축 파일 구성은 그대로 복사해 새 zip 생성 후 `os.replace` | openpyxl 등으로 통째로 다시 저장하면 서식·열 너비·인쇄 설정이 바뀔 수 있습니다. 셀 하나만 바꾸면 나머지는 바이트 단위로 그대로입니다. 저장 후 다시 읽어 검증하고, 엑셀이 파일을 열어 둔 상태라면 교체가 거부되어 안전하게 실패합니다. |
| 수정 충돌 방지 | 저장 요청에 "수정 전 내용"을 함께 보내고, 서버가 현재 셀 내용과 다르면 거부(409) | 엑셀에서 먼저 바뀐 내용을 프로그램이 덮어쓰지 않도록 하기 위함입니다. |
| 전체 검색 | 화면에서 모든 영상의 타임스탬프를 검사해 영상별 개수(`hits`)를 계산 | 엑셀이 수백 개 수준이어도 즉시 반응하도록 서버 왕복 없이 처리합니다. |
| 바로가기 | `URL.searchParams.set('t', 초+'s')` | 유튜브의 시작 시간 지정 방식입니다. |
| 썸네일 | 영상 주소에서 ID를 추출해 `i.ytimg.com/vi/ID/mqdefault.jpg` 로드 | 별도 다운로드 없이 영상마다 한 번씩 표시합니다. 실패하면 ▶ 아이콘으로 대체됩니다. |
| 자동 종료 | 화면이 10초마다 `/api/ping`, 서버는 마지막 신호 후 3분 경과 시 종료 | 백그라운드에 서버가 계속 남지 않도록 하기 위함입니다. (`config.json`의 `auto_exit_minutes`로 조절, 0이면 끔) |

## 6. 안정성·보안 장치
- `127.0.0.1`에만 열려 같은 네트워크의 다른 기기는 접속할 수 없습니다.
- `Host` 헤더를 검사하고, 데이터를 바꾸는 요청에는 전용 헤더(`X-TLM`)가 필요해 외부 웹사이트가 몰래 요청할 수 없습니다.
- 미리보기·열기는 **참고자료로 등록된 파일만** 가능합니다. 미리보기 응답에는 `Content-Security-Policy: sandbox`를 붙이고 HTML은 텍스트로 내려 파일 속 스크립트가 실행되지 않습니다.
- 엑셀은 읽기가 기본이며, 쓰기는 **[엑셀에 저장]을 눌렀을 때 그 셀 하나**와 `timeline-refs.json`, `config.json`, `library/.backup/`뿐입니다.
- 파일이 없으면 ⚠로 표시하고 "다시 연결"을 제공합니다.

## 7. 알려진 한계와 고려할 점
0. **엑셀이 그 파일을 열어 두고 있으면 프로그램에서 저장되지 않습니다.** "엑셀에서 파일이 열려 있어 저장할 수 없습니다"라는 안내가 뜨며 입력한 내용은 편집창에 남습니다. 엑셀을 저장하고 닫은 뒤 다시 저장하세요. 반대로 프로그램에서 수정한 뒤 이미 열려 있던 엑셀에서 저장하면 프로그램의 수정이 덮어써질 수 있으므로, 한 번에 한쪽에서만 편집하는 것을 권합니다.
0-1. **키워드의 추가·삭제는 아직 엑셀에서만 가능합니다.** 프로그램에서 수정되는 것은 내용(C열)과 키워드 버튼 색입니다. 필요하면 키워드 편집도 추가할 수 있습니다.
0-2. 키워드는 글자가 같아야 같은 것으로 봅니다(`가`와 `가나`는 다른 키워드). 표기를 통일해 두면 미리보기가 정확해집니다.
1. **참고자료 연결은 시간(초) 기준입니다.** 엑셀에서 해당 행의 시간을 바꾸면 연결이 끊어진 것처럼 보입니다(데이터는 `timeline-refs.json`에 남아 있습니다). 같은 시간에 여러 행이 있으면 위에서부터 0번, 1번으로 구분합니다.
2. **시트 이름이나 엑셀 파일 이름, 폴더 위치를 바꿔도 연결이 끊깁니다.** 영상 구분 키가 `폴더/파일.xlsx::시트이름`이기 때문입니다. 이름을 바꿔야 한다면 `timeline-refs.json`의 해당 키도 같이 고쳐 주세요.
3. **썸네일은 인터넷 연결이 필요합니다.** 유튜브 주소가 아닌 경우나 오프라인에서는 ▶ 아이콘이 표시됩니다.
4. 엑셀 파일을 **열어 둔 채** 저장 전이라면 이전 내용이 보입니다. 저장하면 자동 반영됩니다. 드물게 읽기가 거부되면 사이드바에 안내가 나옵니다.
5. 재생 시간 칸을 비워 두면 길이를 추정하므로 마지막 구간의 폭이 실제와 다를 수 있습니다. 영상마다 재생 시간을 적어 두는 것을 권합니다.
6. 팀원과 공유하려면 `library/` 폴더(엑셀 + `timeline-refs.json` + 참고자료)를 통째로 공유하세요. 폴더 밖의 파일을 연결하면 절대경로가 저장되어 다른 컴퓨터에서는 열리지 않으므로, 공유할 자료는 `library/` 안에 두는 것을 권합니다.
7. 실제 Windows·유튜브 환경에서의 최종 확인은 직접 해 보셔야 합니다. 제작 환경(Linux)에서는 서버 API, 엑셀 해석, 화면 동작을 테스트했고, Windows 전용 부분(파일 선택창, 기본 프로그램 열기, 폴더에서 보기)과 실제 썸네일 로딩은 테스트하지 못했습니다.

## v1.6 변경: 영상 내 검색, 검색창 확대, 버튼 문구

- **영상 안 검색칸 복원:** 타임라인 막대 카드에 "이 영상 안에서 검색" 입력칸을 넣었습니다. 상태 `S.vq`와 `vterms()`(= 영상 검색어, 비어 있으면 전체 검색어)를 두고, 열린 영상 안의 기능(막대 강조·화살표, ▲▼ 이동, 본문 강조, 키워드 강조, 목록 필터)만 `vterms()`를 쓰게 했습니다. 사이드바 일치 횟수와 전체 요약은 계속 `terms()`(전체 검색어)를 씁니다. 영상을 바꾸면 영상 검색칸은 비워집니다. 이전에는 전체 검색어 하나로 영상 안 표시까지 겸하게 해서 별도 칸이 없어졌던 것입니다.

- 검색 범위 체크박스(본문/키워드/참고자료)는 영상 안 검색에도 동일하게 적용됩니다.

- **문구:** "참고자료 연결" 버튼을 "파일 연결"로 바꿨습니다(섹션 제목 "참고자료"는 유지).

## v1.7 변경: 화면과 서버 버전 불일치 경고

- **원인:** 화면 파일(`web/*`)은 요청할 때마다 디스크에서 읽지만, 서버 코드(`app.py`)는 `run.bat`으로 시작할 때 한 번만 읽습니다. 서버를 다시 시작하지 않고 브라우저만 새로고침하면 화면은 새 버전, 버전 표시와 서버 기능은 이전 버전이 됩니다. 헤더의 버전 표시가 서버가 알려준 값이어서 "한 버전 느리게" 보였습니다.
- **변경:** 화면 파일에 자기 버전(`WEB_VERSION`)을 넣고, 서버가 알려주는 `APP_VERSION`과 비교합니다. 다르면 상단에 노란 경고 막대와 안내 메시지를 띄우고 버전 글자를 빨간색으로 바꿉니다. 헤더에는 이제 화면 버전이 표시됩니다.
- **업데이트 방법:** [종료] 버튼을 누르거나 검은 창을 닫고 `run.bat`을 다시 실행한 뒤 새 탭으로 엽니다.
- 새 버전을 배포할 때는 `app.py`의 `APP_VERSION`과 `web/app.js`의 `WEB_VERSION`을 함께 올려야 합니다.

## v2.0 변경: 타임라인 막대 확대·축소

- **사용법:** 막대 위에서 **마우스 휠**을 굴리면 커서 위치를 중심으로 확대·축소됩니다. 막대 아래 **－ / ＋ / 전체** 버튼으로도 조절하고, 확대한 뒤에는 막대를 **끌어서** 좌우로 이동하거나 아래 슬라이더로 움직입니다. 현재 보는 구간과 배율(예: ×6.0)이 표시되며, 가장 많이 확대하면 10초 구간까지 볼 수 있습니다.
- **구현:** 보는 구간을 `S.zoom = {영상키, 시작초, 끝초}`로 저장하고(`viewRange`·`setView`), 막대 칸·▼ 화살표·눈금(0~5 지점)을 모두 이 구간 기준으로 다시 계산합니다. 구간 밖 칸은 그리지 않고 걸친 칸은 잘라서 그립니다. 클릭 위치도 보는 구간 기준의 시간으로 변환합니다. 끌기는 4px 이상 움직였을 때만 이동으로 보고 클릭(칸 선택)과 구분합니다.
- **자동 이동:** 목록이나 ▲▼ 이동으로 보는 구간 밖의 타임스탬프를 선택하면, 그 항목이 가운데 오도록 구간이 자동으로 옮겨집니다. 다른 영상을 열면 확대는 초기화됩니다.
- 테스트: 40개 스탬프가 10분에 몰린 영상에서 8단계 확대 시 해당 구간만 표시되고 ▼ 화살표가 구간 안의 일치 항목에만 나오는 것을 확인했습니다.
- **PC에 반영되지 않던 문제(원인과 조치):** 파일을 내려받는 폴더에 복사한 직후 바로 PC로 보내면 직전 버전이 전달되는 경우가 있었습니다. 복사 후 몇 초 기다렸다가 전송하고, 전송 뒤 PC의 파일 내용을 다시 읽어 버전을 확인하도록 순서를 바꿨습니다.

  1. **글자 표현 차이:** 구글 시트·복사·붙여넣기 과정에서 한글이 자모 분리형(NFD)이거나 줄바꿈 없는 공백(NBSP)·보이지 않는 공백이 섞이면 눈으로는 같아도 글자 비교가 맞지 않습니다. 검색어, 본문, 키워드를 모두 NFC로 정규화하고 특수 공백을 일반 공백으로 바꿔 비교하도록 했습니다(`norm()`). 검색 강조와 키워드 일치 강조도 같은 기준입니다.
  2. **검색 범위 체크박스:** 본문 체크를 꺼 둔 상태에서는 본문이 검색되지 않습니다. 결과가 없을 때 "(검색 범위: 키워드만)"처럼 현재 범위를 함께 알려 주도록 했습니다(전체 검색 요약과 영상 안 검색 모두).
- 테스트: 자모 분리형 한글과 NBSP가 들어 있는 셀을 "본문", "메모장", "방송 시작"으로 검색해 모두 일치하는 것을 확인했고, 본문·키워드 범위를 끄면 안내 문구가 나오는 것을 확인했습니다.

## v2.4 변경: 검색식(&, OR, 괄호, 따옴표)과 키워드로 찾기

### 검색식
- **문법:** `&`(또는 `AND`, 띄어쓰기)는 모두 포함, `OR`는 하나라도 포함, `( )`는 묶어서 먼저 계산, `'두 단어'` 또는 `"두 단어"`는 띄어쓰기가 있는 단어입니다. 예) `(가 OR 나) & 다`는 가 또는 나가 있고 다도 있는 항목, `'가 나' & 다`. `OR`와 `AND`는 대문자여야 연산자로 인식하고, 소문자 `or`는 일반 단어입니다. 기존처럼 띄어쓰기로만 쓴 검색어는 그대로 모두 포함(AND)입니다.
- **우선순위:** 괄호 > AND(`&`, 띄어쓰기) > OR. 그래서 괄호가 없는 `가 OR 나 & 다`는 `가 OR (나 & 다)`로 계산됩니다. 화면에는 해석된 식(예: `해석: (가 OR 나) & 다`)을 검색창 아래에 보여 줘서 의도와 같은지 확인할 수 있습니다.
- **구현:** `parseQuery()`가 검색어를 토큰(검색어, `&`, `OR`, `(`, `)`)으로 나눈 뒤 재귀 하강 파서(OR → AND → 괄호/검색어)로 식 트리를 만들고, `evalNode()`가 각 타임스탬프의 검색 대상 글자(범위 체크박스 기준)에 대해 참/거짓을 계산합니다. 같은 검색어는 캐시해서 다시 해석하지 않습니다. 강조 표시용 단어 목록은 식 안의 모든 검색어를 모은 것입니다.
- **잘못된 식:** 괄호 짝이 안 맞거나 연산자가 비어 있으면 오류로 멈추지 않고 가능한 범위에서 해석하고, 어떤 문제인지 경고를 함께 보여 줍니다.
- **조건의 단위:** 조건은 **한 타임스탬프** 안에서 판단합니다. 즉 `가 & 다`는 같은 타임스탬프에 가와 다가 모두 있어야 일치하며, 같은 영상의 서로 다른 타임스탬프에 따로 있으면 일치하지 않습니다.
- 검색창 아래에 검색 방법 안내를 항상 표시합니다. 영상 안 검색칸과 범위 체크박스에도 같은 검색식이 적용됩니다.
- `OR` 검색에서 일치 횟수 배지는 "일치한 타임스탬프 수"이고, 마우스를 올리면 나오는 단어 일치 횟수는 식 안의 모든 단어를 합산한 값입니다.

### 키워드로 찾기
- 검색창 아래 **🏷 키워드로 찾기 (N)** 버튼을 누르면 전체 문서에 있는 키워드가 모두 펼쳐지고, 키워드마다 옆에 그 키워드가 적힌 **타임스탬프 수**가 표시됩니다. 정렬은 숫자·기호, 알파벳, 가나다, 기타 문자 순이고 같은 종류 안에서는 사전 순입니다. 위쪽 입력칸으로 목록을 거를 수 있습니다.
- 키워드를 누르면 "다른 키워드 찾기"와 같은 큰 창이 열려 그 키워드가 있는 모든 타임스탬프(영상별로 묶음)를 보여 주고, 항목을 누르면 그 위치로 이동합니다. 색 지정과 헥스코드도 같은 창에서 할 수 있고, 바꾸면 목록의 키워드 색도 함께 바뀝니다.
- 대소문자 차이(`Abc`/`abc`)는 같은 키워드로 묶이며, 가장 많이 쓰인 표기를 대표로 보여 줍니다. 띄어쓰기나 다른 글자가 다르면 다른 키워드입니다.
- 목록은 엑셀을 다시 읽을 때(저장, 새로고침, 키워드 편집 후)마다 새로 만들어집니다.

### 폴더 위치를 옮길 때(참고)
- 참고자료 연결, 키워드 색, 아이콘은 라이브러리 폴더 안의 `timeline-refs.json`에 있으므로 **그 파일까지 함께 옮긴 뒤** [폴더 변경]으로 새 위치를 지정하면 유지됩니다. 폴더 안의 구조(하위 폴더, 파일 이름, 시트 이름)가 같아야 하고, 폴더 안에 있던 참고 파일은 상대 경로라 같이 따라갑니다. 폴더 밖의 파일은 절대 경로라 그 파일을 옮기지 않았을 때만 연결이 유지됩니다. 엑셀만 옮기면 설정은 따라가지 않습니다.


## v2.5 변경: 키워드 목록 초성 인덱스·정렬, 키워드 창의 쪽 이동·시간순·세부검색

### 키워드로 찾기(목록)
- **초성/알파벳 인덱스 줄:** 목록 위에 `# A B … Z ㄱ ㄴ … ㅎ 기타` 버튼이 나오고, 누르면 그 묶음의 시작 위치로 스크롤합니다. 현재 보이는 묶음은 강조되며, 실제로 존재하는 묶음만 표시합니다.
- **묶음 규칙(`groupOf`):** 첫 글자가 숫자·기호면 `#`, 영문이면 대문자 알파벳, 한글 음절이면 초성(쌍자음 ㄲ·ㄸ·ㅃ·ㅆ·ㅉ는 ㄱ·ㄷ·ㅂ·ㅅ·ㅈ에 합침, 초성은 `(코드−0xAC00)/588`의 몫으로 계산), 그 외 문자는 `기타`입니다. 묶음 순서는 기존 정렬(숫자·기호 → 알파벳 → 가나다 → 기타)과 같아 목록이 끊기지 않습니다.
- **정렬 전환:** `이름순`(묶음 표시, 인덱스 사용)과 `개수순`(타임스탬프 수가 많은 순, 같으면 이름순)을 전환합니다. 개수순에서는 묶음이 의미가 없으므로 인덱스 줄을 숨깁니다. 위쪽 입력칸 필터는 두 방식에서 모두 적용됩니다.

### 키워드 창(큰 창)
- **쪽 이동:** 20곳씩 나누어 보여 주고, 아래쪽에 `« ‹ 이전 | n / m쪽 · N곳 | 다음 › »` 버튼이 있습니다. 목록이 한 쪽 이내면 숨깁니다. 창에서 입력칸 밖에 있을 때 키보드 ←/→로도 넘길 수 있습니다.
- **정렬:** `영상별(날짜순)`은 기존처럼 현재 영상을 먼저, 이후 업로드일 순으로 영상 제목 머리글 아래에 묶어서 보여 줍니다. `시간순(타임스탬프)`은 영상과 상관없이 시간 값이 작은 것부터 한 줄로 늘어놓고, 항목마다 영상 제목·날짜를 작게 붙입니다. 같은 시간이면 영상 날짜순입니다.
- **세부검색:** 창 안의 검색칸에 쓴 식이 이 키워드가 있는 타임스탬프 안에서만 적용됩니다. 문법은 전체 검색과 같고(`&`, `OR`, `( )`, `'두 단어'`), 판단 대상은 메모 본문·그 타임스탬프의 키워드·영상 제목입니다. 일치하는 글자는 노란색으로 표시하고, 본문 미리보기가 160자로 잘리는 경우 첫 일치 위치가 보이도록 앞부분을 잘라 냅니다. 결과 수는 `전체 N곳 중 M곳`으로 표시합니다.
- **구현 구조:** 한 번 만든 목록(`items`)에서 `view()`가 세부검색 → 정렬 순으로 걸러 `list`를 만들고, `render()`가 현재 쪽만 잘라 그립니다. 정렬·검색어·쪽 번호는 창 안의 작은 상태 객체(`kst`)에 두며, 상태가 바뀔 때마다 `render()`만 다시 부릅니다. 색 지정 영역의 코드는 그대로입니다.

### 시험 방식
- 실제 엑셀 대신 시험용 가짜 엑셀(영상 9개, 타임스탬프 약 430개, 키워드 77개, 한 키워드는 235곳)을 만들어 서버에 연결하고, 헤드리스 브라우저에서 인덱스 이동·정렬·쪽 이동·세부검색·항목 클릭 이동을 자동으로 확인했습니다. 세부검색 결과 수는 데이터에서 직접 센 값과 일치했습니다(`(나 OR 다) & 사` 20곳, `'two words' & 나` 48곳).

### 초성/알파벳 버튼 = 필터
- v2.5에서는 버튼이 해당 위치로 스크롤하는 방식이라, 목록 끝쪽 묶음(ㅍ·ㅋ·ㅎ)은 스크롤 한계 때문에 위쪽 묶음(ㅇ)에서 멈춰 보였습니다. v2.6은 스크롤 이동을 없애고 **누른 묶음만 표시**합니다.

- `영상별/시간순(타임스탬프)` 선택지를 **`업로드 날짜 ↑ 오래된 순` / `↓ 최신 순`** 으로 바꿨습니다. 처음 값은 화면 위쪽 정렬 버튼(`S.sortDesc`)을 따릅니다. 날짜가 없는 영상은 항상 맨 뒤이고, 같은 영상 안에서는 시간 오름차순입니다. v2.5의 "현재 영상 먼저" 규칙은 정렬이 예측 가능하도록 없앴고, 현재 영상은 머리글에 `(현재 영상)`으로만 표시합니다.
- 영상 제목 머리글은 날짜가 바뀔 때마다(영상이 바뀔 때마다) 붙고, 쪽이 넘어가면 그 쪽의 첫 항목 위에 다시 붙습니다.

### 시험(가짜 데이터)

## v2.7 변경: 즐겨찾기 (폴더 계층, 별 버튼, 관리창, 검색 시 상단 섹션)

### 사용 방법
- **추가·편집:** 타임라인 목록의 각 타임스탬프 왼쪽 **☆ 버튼**(또는 아래 상세 영역의 ☆)을 누르면 팝업이 열립니다. 이름(기본값은 메모 앞부분 또는 시간), 메모(선택), **저장 위치(폴더 트리)** 를 정하고 저장하면 ★로 바뀝니다. 이미 즐겨찾기인 항목의 ★를 누르면 편집·삭제 창이 열립니다. 창 안에서 **＋ 새 폴더**로 선택한 폴더 아래에 하위 폴더를 만들 수 있고, 마지막에 쓴 폴더가 다음 추가 때 기본 위치가 됩니다.
- **관리:** 위쪽 **★ 즐겨찾기 (N)** 버튼의 관리창은 왼쪽이 폴더 트리(폴더마다 개수), 오른쪽이 선택한 폴더의 즐겨찾기 목록입니다. 폴더는 `＋ 폴더`(하위 폴더 만들기), `✎ 이름`, `📂 이동`(다른 폴더 안으로), `🗑 삭제`(하위 폴더·안의 즐겨찾기까지 삭제, 확인 창 있음)를 지원하고, 즐겨찾기는 행을 눌러 열기, `✎`(이름·메모·위치 수정), `📂`(다른 폴더로 이동), `🗑`(삭제)를 지원합니다. 위쪽 검색칸은 **모든 폴더**의 즐겨찾기를 같은 검색식(`&`, `OR`, `( )`, `'두 단어'`)으로 찾고 해석된 식을 보여 줍니다.
- **검색할 때:** 전체 검색을 하면 왼쪽 목록 맨 위에 **★ 즐겨찾기 N개** 구역이 먼저 나오고, 그 아래 **🎞 영상** 구역에 기존 영상 목록이 이어집니다. 즐겨찾기는 이름·메모·폴더 이름·영상 제목·해당 타임스탬프의 본문/키워드/참고자료(범위 체크 기준)에서 일치를 판단하고, 누르면 그 영상의 그 위치로 이동합니다. 검색 요약에도 `★ N개`가 붙습니다. 키워드 큰 창에서는 그 키워드가 있는 즐겨찾기를 맨 위 **★ 즐겨찾기** 구역(첫 쪽, 최대 10곳)에 따로 보여 주고, 목록의 즐겨찾기 항목 앞에는 ★가 붙습니다.

### 저장 구조 (`timeline-refs.json`의 `bookmarks`)
```
"bookmarks": {
  "folders": [ {"id": "f…", "name": "폴더 이름", "parent": "부모 폴더 id 또는 빈 문자열(최상위)"} ],
  "items":   [ {"id": "b…", "v": "영상키(파일.xlsx::시트)", "e": "타임스탬프 키(초#순번)", "sec": 초,
                "title": "영상 제목(복사본)", "name": "이름", "note": "메모", "folder": "폴더 id", "ts": 만든 시각} ]
}
```
- 한 타임스탬프(`v`+`e`)에는 즐겨찾기를 하나만 둡니다. 영상 제목과 시간(`title`, `sec`)은 나중에 엑셀이 바뀌어도 목록에 무엇이었는지 보이도록 함께 저장한 복사본입니다.
- **엑셀이 바뀐 경우:** 타임스탬프 키가 사라지면 같은 영상에서 저장된 시간과 5초 이내로 가장 가까운 타임스탬프로 이동하고 안내 문구를 띄웁니다. 영상 자체가 없으면 목록에 `⚠ 영상을 찾을 수 없음`을 표시하고 이동 대신 안내만 합니다(항목은 지워지지 않으므로 파일을 되돌리면 다시 연결됩니다).
- **서버 검증(`clean_bookmarks`):** 폴더 500개·즐겨찾기 5000개까지, id는 영문·숫자·`_`·`-` 40자 이내, 이름 길이 제한, 없는 부모 폴더는 최상위로, **폴더 순환(A↔B)은 끊고**, 중복 id·중복 타임스탬프·빈 이름 폴더는 버립니다. 폴더 구조가 어긋나도 파일이 깨지지 않도록 저장할 때마다 정리합니다.
- 키워드 색·아이콘·참고자료와 같은 파일에 저장되므로 **폴더를 옮길 때 `timeline-refs.json`을 함께 옮기면** 즐겨찾기도 유지됩니다(영상 키가 같을 때).

### 구현 메모
- 폴더 트리는 하나의 함수 `bmTree(host, 옵션)`로 만들어 추가창·관리창·폴더 선택창(`bmPickFolder`)이 함께 씁니다. 접힘 상태(`bmCollapsed`)는 공유합니다.

- 같은 ID라도 `normUrl`/`ytId`는 기존 함수를 재사용(`watch?v=`, `youtu.be`, `shorts`, `live`, `embed`).

### 6. v2.8 추가 — 플레이어 현재 위치를 추가 창 기본 시간으로

## v2.13 — 타임라인 목록을 안쪽 스크롤로 변경 (v2.12 방식 대체)

### 1. 왜
v2.12는 바깥 화면(`#main`) 전체를 스크롤해서 선택 줄을 맨 위로 올렸기 때문에, 영상·막대·본문이 화면 밖으로 밀려났습니다. 막대 위치, 본문 내용, 목록 안의 위치를 **동시에** 보려면 목록만 안에서 움직여야 합니다.

### 2. 구현
- `#list`를 자체 스크롤 상자로: `max-height:clamp(300px,55vh,640px); overflow:auto; overscroll-behavior:contain`(`style.css`). 항목이 적으면 상자도 작아집니다. `overscroll-behavior:contain`은 목록 끝에서 바깥 화면까지 같이 스크롤되는 것을 막습니다.
- `scrollSel(focus)`(`app.js`): `focus`일 때 `#list.scrollTo({top: list.scrollTop + row.top − list.top − 4, behavior:'smooth'})` — 선택 줄이 **목록 상자의 맨 윗줄**에 옵니다. 동작 줄이기 설정이면 즉시 이동. 목록을 직접 눌러 선택할 때(`focus` 거짓)는 `scrollIntoView({block:'nearest'})`.
- 바깥 화면: 목록 윗단이 화면 밖(위 60px 미만이거나 아래 160px 이내)일 때만 `#main`을 최소한 움직여 목록 윗단을 높이의 45% 지점에 맞춥니다. 이미 보이면 바깥 화면은 움직이지 않습니다.
- `updateList`는 목록을 다시 그릴 때 `scrollTop`을 저장·복원해 선택·즐겨찾기 토글로 위치가 튀지 않습니다.
- 끝 여백: 목록이 넘칠 때만 `.pad` 클래스를 붙여 `::after`(높이 = 상자 높이 − 44px)로 맨 끝 줄도 맨 윗줄까지 올라오게 합니다(`--lh` 변수에 상자 높이 저장). v2.12의 `50vh` 바깥 여백은 제거.

### 3. 시험과 한계
- 동작 줄이기 모드에서: 16번째 줄 선택 → 줄 윗단이 목록 상자 윗단에서 4px. 마지막 줄 선택 시 여백이 있어 맨 위 근처까지 올라옴(여백 보정 후 44px로 조정).

## v2.15 — Template.xlsx 지정, '템플릿'/'Template' 시트 항상 제외

### 1. 시트 제외 규칙 (`app.py`: `is_template_sheet`, `parse_sheet`)
- 시트 이름이 정확히 **`템플릿` 또는 `Template`**(앞뒤 공백 무시, 대소문자 무시: `TEMPLATE`, `template` 포함)이면 **내용(B1·B2)이 채워져 있어도 항상 목록에서 제외**합니다(`parse_sheet`가 `None`). 진단의 시트 인식 탭에는 "템플릿 시트라서 항상 제외"로 표시됩니다.
- 그 밖에 이름에 '템플릿'/'template'가 **들어 있는** 시트(`템플릿 (2)`, `Blender template 팁` 등)는 예전처럼 **제목·주소가 모두 비어 있을 때만** 제외합니다. 복사해서 채운 `template (2)`나 이름에 단어가 우연히 들어간 영상 시트가 사라지지 않게 하려는 것입니다(이름 규칙을 '포함'으로 넓히면 정상 영상이 숨겨질 위험).
- 타임라인 추가 API는 템플릿 시트에는 추가할 수 없다고 안내합니다.

### 2. 라이브러리 맨 위의 Template.xlsx (`list_xlsx`, `find_template_file`, `create_workbook`)
- 라이브러리 **최상위 폴더**의 `Template.xlsx`(대소문자 무시; 호환용으로 `템플릿.xlsx`, `_Template.xlsx`, `_템플릿.xlsx`도 인식, 이 순서로 우선)는 새 문서를 만들 때 복사할 양식이므로 **문서 목록에서 제외**합니다(`list_xlsx`가 최상위에서만 건너뜀). 하위 폴더의 같은 이름 파일은 일반 문서입니다.
- `＋ 새 엑셀 문서`는 이 파일을 통째로 복사합니다(안에 샘플 시트가 있으면 그것도 같이 복사됨). 읽히지 않으면 내장 양식으로 대체. 점검 탭에 "내 템플릿 파일 (Template.xlsx, 목록에서는 제외)"로 표시.
- `＋ 영상(시트) 추가`(`_pick_template_sheet`): **그 문서 안의** 템플릿 시트를 복사합니다. 이름이 정확히 `템플릿`/`Template`인 시트를 먼저, 없으면 '이름에 템플릿이 들어 있고 제목·주소가 빈' 시트. 복사 원본의 B1·B2는 비어 있어야 합니다(`( )` 안내 문구는 빈 것으로 간주) — 채워져 있으면 샘플 내용이 새 시트에 딸려 가므로 원본으로 쓰지 않고 내장 양식으로 만듭니다. 표·그림 등 개체가 있는 템플릿도 내장 양식으로 대체.
- 한계: 루트의 `Template.xlsx`에서 시트를 **다른 기존 문서로 가져와** 복사하지는 않습니다(서식 번호가 문서마다 달라 깨질 수 있음). 템플릿 시트가 없는 기존 문서는 내장 양식을 쓰며, 새 문서는 항상 Template.xlsx를 복사하므로 템플릿 시트를 갖고 시작합니다.

### 3. 시험
- 가짜 라이브러리: 루트 `Template.xlsx`는 목록 제외·점검에서 인식, `Template2.xlsx`는 일반 문서. `TEMPLATE`(내용 있음)·`템플릿`(내용 있음)은 제외, `template (2)`(내용 있음)·`Blender template 팁`은 영상으로 표시, `템플릿 (3)`(빈 것)은 제외.
- `create_workbook` → Template.xlsx 복사(시트 `Template` 포함), 거기에 영상 시트 추가 → 템플릿 시트 복사(`base: template`). 채워진 `Template` 시트만 있는 문서는 내장 양식(`base: builtin`)으로 추가되고 `Template` 시트는 계속 제외.

## v2.19 — 키워드 삭제(×) 뒤에 추천창이 열리던 문제

- 원인: 키워드 편집 영역은 ×를 누르거나 추가·Backspace를 할 때마다 `draw()`로 입력칸을 새로 만들고 `focus()`를 호출하는데, `attachKwSuggest`가 `focus` 이벤트에서도 추천창을 열었습니다. 그래서 사용자가 아무것도 입력하지 않았는데도 "자주 쓰는 키워드"가 떴습니다.

  - `workbook.xml`의 `<sheet>` 태그, `workbook.xml.rels`의 관계, `[Content_Types].xml`의 Override, 시트 부품 파일을 뺍니다. 이 시트에서만 쓰는 부품(메모, 그림 등)은 다른 곳에서 참조하지 않을 때만 같이 뺍니다(`.rels`를 전부 훑어 확인).
  - 시트 번호(순번)를 쓰는 정보를 고칩니다: `definedName`의 `localSheetId`(지운 시트 것은 삭제, 뒤 시트는 1씩 감소), 지운 시트를 가리키는 이름 범위 삭제, `workbookView`의 `activeTab`·`firstSheet` 보정. 엑셀이 다시 만드는 `calcChain.xml`은 지운 시트를 가리키면 복구 창이 뜰 수 있어 함께 뺍니다.
  - 문서에는 보이는 시트가 하나 이상 남아야 하므로 마지막 시트는 막고(409), 템플릿 시트는 이 기능으로 지우지 못합니다.
  - 검증: 지운 시트 외의 시트 이름·셀 내용이 저장 전과 같은지 `_same_other_sheets`로 비교합니다.
- **`_rename_sheet_file` / `rename_video_sheet`** — 이름 변경. 한 번의 저장으로 시트 이름(`workbook.xml`의 `name`, 이름 범위 안의 시트 참조)과 제목(B1, `set_cell_inline`)을 함께 바꿉니다. 시트 이름은 기존 `clean_sheet_name` 규칙(31자, 금지 문자)에 더해 같은 문서 안에서 대소문자 무시로 중복을 막고, 템플릿 이름(목록에서 제외되는 이름)으로는 바꾸지 못하게 합니다. 다른 시트의 수식이 이 이름을 참조하면 깨지므로 막습니다. 검증은 이름 순서, B1을 뺀 나머지 셀, 새 제목, 타임스탬프 개수를 확인합니다.
- **`move_video_sheet`** — 위치 이동. 서식까지 복사하는 대신, 이미 검증된 경로를 재사용합니다: 원본을 `parse_sheet`로 읽고 → 대상 문서에 `add_video_sheet`로 새 시트를 만들고(템플릿 시트 복사) → `add_entry`로 타임스탬프를 시간순으로 채웁니다(`import_apply`와 같은 방식). 이 방식은 서로 다른 엑셀 파일 사이의 스타일·공유 문자열 번호 문제를 피하는 대신 셀 서식과 그 밖의 칸은 옮겨지지 않습니다.
  - 안전장치: ① 시간 형식을 읽을 수 없는 행이 있으면 내용이 사라지지 않도록 옮기지 않습니다(409). ② 시작 전에 대상 문서의 바이트를 메모리에 보관했다가, 생성·채우기·검증·원본 삭제 중 어느 단계에서든 실패하면 대상 문서를 그 내용으로 되돌립니다(바뀌었을 때만). ③ 옮긴 결과를 다시 읽어 (시간, 내용, 키워드) 목록·제목·주소가 원본과 같은지 확인한 뒤에야 원본에서 삭제합니다. ④ 대상에 같은 이름의 시트가 있으면 `_unique_sheet_name`이 `이름 (2)`처럼 번호를 붙입니다.
  - 같은 초에 있는 타임스탬프는 원래 순서대로 붙으므로 타임스탬프 키(`초#순번`)가 그대로 유지되어 참고자료 연결이 끊기지 않습니다.
- **연결 정보 이전 (`timeline-refs.json`)** — 영상의 키는 `문서::시트`라서 이름 변경·이동 때 바뀝니다.
  - `remap_video_refs(old, new, title)`: `videos`, 즐겨찾기 항목의 `v`(제목도 갱신), `icons`의 `video:` 키를 새 키로 옮깁니다.
  - `drop_video_refs(key)`: 삭제한 영상의 연결·즐겨찾기·아이콘을 정리하고, 정리한 내용은 `timeline-refs.removed.json`(종료 때 정리와 같은 보관 파일)에 남깁니다.
  - 엑셀 저장이 끝난 뒤에 실행하며, 이 단계가 실패해도 엑셀 작업 결과는 유지하고 응답에 `refsWarning`을 담습니다(남은 흔적은 종료 때 정리가 처리).

### 2. 화면 (`web/app.js`, `style.css`, `index.html`)
- `vItem()`에 `⋯` 버튼(`data-vm`)을 추가했습니다. `#side`의 위임 클릭 핸들러에서 가장 먼저 처리해, 영상이 열리지 않고 메뉴만 열립니다.
- `openVMenu()`: `body`에 붙는 `position:fixed` 메뉴. 아래 공간이 모자라면 위로 펼치고, 바깥 클릭·Esc·스크롤·창 크기 변경·목록 다시 그리기(`renderSide`)에서 닫습니다. ↑↓ 키로 이동합니다.

- `vmDelete()`: 기존 `ask()` 확인창을 재사용하되 `danger` 옵션(빨간 버튼)을 추가했습니다. 지워질 타임스탬프·참고자료·즐겨찾기 개수와 백업 위치를 보여 줍니다.
- `vmMove()`: 즐겨찾기 폴더 이동창(`bmPickFolder`)과 같은 모양의 선택창(`#vmpick`). 폴더·엑셀 문서 트리를 `S.lib.files`로 만들고, 현재 문서는 비활성으로 표시합니다. 창 안의 `＋ 새 엑셀 문서`는 기존 `/api/doc/create`를 써서 선택한 폴더에 문서를 만든 뒤 바로 고르게 합니다. 옮기는 동안은 Esc로 닫히지 않습니다.
- 편집(`S.editing`) 중에는 세 작업 모두 막고 안내합니다.

### 3. 확인한 것
- 엑셀로 저장한 것과 같은 구조(공유 문자열, 메모, 이름 범위, 숨김 시트, 계산 체인, 열린 탭 번호)의 시험 파일에서 세 작업을 실행하고, openpyxl과 LibreOffice로 결과 파일이 열리는지 확인했습니다. 실패 경로(시간 오류 행, 주소 없음, 삭제 단계 실패 시 대상 복원, 마지막 시트, 중복·금지 이름)는 파일이 바이트 단위로 그대로인지 확인했습니다.

## v1.2.0 — 새 버전 알림 기본 꺼짐, 경로 숨기기

방송인 등 개인정보에 민감한 사용자에게 배포하는 것을 고려해, 외부 접속이 저절로 일어나지 않게 하고 화면에 나오는 경로를 가릴 수 있게 했습니다. 기능이 늘었으므로 MINOR 자리를 올렸습니다(`1.2.0 (2026-11-20)`). 1.1.0은 별도 릴리스 없이 이 버전에 포함됩니다.

### 1. 새 버전 알림 기본값 (`app.py`)
- `DEFAULT_CONFIG["update_check"]`를 `True` → `False`로 바꾸고, `check_update()`의 `cfg.get("update_check", ...)` 기본값도 `False`로 맞췄습니다. 두 곳이 어긋나면 `config.json`에 값이 없는 사용자에게 한쪽 기본값이 적용되므로 함께 바꿉니다.
- `load_config()`는 기본값 위에 `config.json`을 덮어쓰는 구조(`cfg.update(...)`)라서, **이미 `update_check`가 저장된 사용자의 설정은 그대로 유지**됩니다. 기본값 변경은 값이 없는 새 사용자(또는 설정을 한 번도 건드리지 않은 사용자)에게만 영향을 줍니다.
- 설정 화면(`web/app.js`의 `updHtml`)의 체크박스 문구에 "켜면 하루 한 번 GitHub에 접속하며, 이때 IP가 GitHub에 전달됩니다"를 넣었습니다. 정보 창(`web/index.html`)의 안내도 같은 내용으로 고쳤습니다.

### 2. 경로 숨기기 (`web/app.js`)
- 저장: `localStorage`의 `tlm-hide-paths`(`'1'`이면 켜짐). 테마 설정과 같이 **브라우저별**로 저장하며 서버 설정(`config.json`)은 건드리지 않습니다. 저장소 접근이 막힌 환경에서는 `try/catch`로 꺼짐으로 처리합니다. 기본값은 꺼짐입니다.
- 헬퍼: `hidePaths()`(켜짐 여부), `showPath(p)`(켜짐이면 `●●●●●● (경로 숨김)`, 아니면 원래 경로), `applyPathHide()`(왼쪽 위 `#libpath` 갱신).
- 가리는 곳(절대 경로만): 왼쪽 위 라이브러리 폴더 경로, 영상이 없을 때 안내 화면의 폴더 경로, 참고자료 버튼의 툴팁(`title`), 참고자료 이름 변경 창의 경로, 참고자료 뷰어 제목 아래 경로, 진단 창의 라이브러리 폴더 줄과 "찾을 수 없는 참고자료" 경로, 폴더 변경 입력창의 기본값(숨김 중이면 비워 둠).
- 가리지 않는 곳: 엑셀 파일·폴더 이름(라이브러리 안의 상대 경로 `f.path`). 이것은 목록에 나오는 내용 자체라 가리면 쓸 수 없습니다. 서버가 돌려주는 오류 문구에 경로가 들어 있는 경우, 탐색기·파일 선택창·브라우저 주소창(`127.0.0.1:포트`만 보임)도 대상이 아닙니다.
- 설정 창: 새 구역 "경로 숨기기"(`#stHide`). 토글하면 저장 → `applyPathHide()` → 선택된 영상이 없으면 `renderEmpty()`, 있으면 `updateAll()`로 갱신합니다. `renderVideo()`는 플레이어를 다시 불러오므로 쓰지 않았습니다.

### 3. 문서
- `README.md`: "개인정보·보안"에 외부 접속 표(영상 재생, 제목 자동 입력, 새 버전 알림)와 방송 시 주의를 넣고, 영문 요약에 한 줄을 추가했습니다. "개발자에게 보내는 데이터가 없다"는 약속처럼 읽혀서 "이 프로그램의 코드에는 … 기능이 없습니다"로 코드 기준 표현을 썼습니다.
