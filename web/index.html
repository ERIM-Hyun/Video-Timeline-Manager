YouTube 영상 재생 (YouTube API Services 사용 고지)

이 프로그램은 YouTube API Services(YouTube 임베드 플레이어)를 사용해 영상을 재생합니다. 이 프로그램을 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주됩니다. 영상 재생 중에는 YouTube/Google이 자체 방침에 따라 사용자 정보(IP 주소, 쿠키 등)를 수집·처리할 수 있습니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침
  • YouTube API 서비스 약관
  • YouTube API 서비스 개발자 정책
  • YouTube 임베드 플레이어 문서

이 프로그램이 다루는 정보

  • 엑셀 파일, 참고자료 연결, 키워드 색상, 아이콘 설정은 사용자 PC(또는 사용자가 지정한 폴더)에만 저장되며 이 프로그램이 외부로 전송하지 않습니다.
  • 유튜브 영상·이미지(썸네일)를 내려받거나 복사해서 저장하지 않습니다. 영상 화면은 유튜브 플레이어가 직접 표시합니다.
  • 영상 제목, 주소, 업로드 날짜는 사용자가 엑셀에 직접 입력한 값입니다.
  • 새 버전 알림이 켜져 있으면(설정에서 끌 수 있음) 하루 한 번 GitHub에 최신 릴리스 번호만 조회합니다. 이때 사용자의 IP 주소가 GitHub에 전달되며, 그 밖의 정보는 보내지 않고 파일을 자동으로 바꾸지도 않습니다.
  • 영상 오른쪽의 ⋯ 메뉴에서 이름 변경(영상 제목·시트 이름), 위치 이동(다른 엑셀 문서로), 삭제를 할 수 있습니다. 작업 전에 해당 엑셀 파일을 자동 백업합니다(library/.backup).
  • [다른 엑셀 불러오기]는 선택한 파일을 읽기만 하며(원본은 수정하지 않음), 고른 타임라인의 시간·내용·키워드만 내 엑셀에 추가합니다.

알아두실 점

  • 올린 사람이 임베드를 막은 영상은 이 안에서 재생되지 않습니다. 이 경우 [유튜브에서 열기]를 사용하세요.
  • 광고는 유튜브 정책에 따라 플레이어에 표시될 수 있으며, 이 프로그램은 이를 막거나 바꾸지 않습니다.
  • 위 내용은 법률 자문이 아니며 약관은 바뀔 수 있습니다. 정확한 내용은 위 링크의 원문을 확인해 주세요.
